# Fundación Artística y Cultural Barrunto

Este proyecto es el sitio web oficial de la Fundación Artística y Cultural Barrunto.

## Estructura del Proyecto
- **HTML**: Contiene el diseño principal de las páginas.
- **CSS**: Define los estilos visuales.
- **JavaScript**: Añade interactividad.

## Cómo acceder
Puedes visitar el sitio web desde el siguiente enlace:  
[Fundación Barrunto](https://fundacion-artistica-y-cultural-barrunto-7a5953.gitlab.io)

## Requisitos
Para colaborar o ejecutar este proyecto localmente, necesitas:
- Un navegador web actualizado.
- Un editor de código como Visual Studio Code.
- GIT para clonar el repositorio.
